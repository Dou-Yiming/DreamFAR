01Method

DreamFAR is a latent flow-matching world model: a tokenizer encodes each camera view into a compact latent, and a causal transformer predicts the next latent from the action, a window of recent latents and a few long-term memory frames. During rollout its own predictions become its history, so one network simulates recorded actions, a policy or a human operator.

1Unit-sphere tokenizer

Each camera view is encoded as per-position latents projected onto the unit sphere and decoded back to pixels by a flow decoder.

2Contact-based memory

When the robot makes or breaks contact with an object, DreamFAR inserts the corresponding keyframe into contact memory, indexed by end-effector pose.

3Streaming transformer

DreamFAR uses a causal transformer with a number of design decisions that make it well suited to streaming and long-horizon generation.

2.2Comparison against baselines

The video shows a 60-s rollout on an episode of the “write a sentence on a whiteboard” task, DreamFAR against the existing baselines. DreamFAR is the only model that keeps the scene layout and the manipulated objects consistent over the whole minute and even predicts writing on the whiteboard that resembles the ground truth. The curves show metric drift on ABC over one minute. DreamFAR degrades the slowest on all three metrics and significantly outperforms all baselines.

2.4Co-training with simulated demonstrations

DreamFAR enables real-time teleoperation without a real robot, so we collect 75 demonstrations of the “place bags of chips into a basket” task both on the real robot and inside the simulator. The π0 policy fine-tuned on the combination of both nearly doubles the real-only performance.

2.5Ablation on memory mechanism

Contact-based memory keeps placed objects persistent. Three models with the same architecture but different memory selection: without memory the bin is empty, sparse time-strided memory hallucinates its contents, and contact-based memory matches the real observation.
